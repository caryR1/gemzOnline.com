# GemsOnline.com Hub

Static corporate hub for Gems Online LLC.

## Destinations
- Travel — travel.gemsonline.com
- Solar — solar.gemsonline.com
- Homes — homes.gemsonline.com
- Automate — automate.gemsonline.com

## Stack
Plain HTML, CSS and minimal JavaScript. No framework or database.

## Deployment
Deploy the repository root as the document root for gemsonline.com on Hostinger.

## Design
The site is intentionally lightweight: a corporate introduction and four prominent launch cards. Production photography/logo assets can be added without changing the page architecture.
